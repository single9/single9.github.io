I started out building PHP websites with frameworks like CodeIgniter and Smarty, then moved into embedded systems development, working with microcontrollers such as the 8051, AVR, Microchip, mbed, and TI MSP430G2. I also researched Node.js during this period and applied it across several projects.

目前主要使用 Rust、Node.js、Golang 等程式語言開發網路應用程式、伺服器程式、監控系統以及系統架構規劃、設計。

Currently I primarily use Rust, Node.js, and Golang to build web applications, backend services, monitoring systems, and to plan and design system architecture.

專長涵蓋後端系統架構設計（多地區、Serverless、微服務）、雲端原生開發（AWS ECS、AWS Lambda、GCP、Docker、Kubernetes）、多語言後端開發（Rust、Node.js、Golang）、CI/CD 與 DevOps 流程建置、Monorepo 與工程治理、技術團隊管理與帶領，以及 API 與系統整合、機器學習服務整合等開發經驗。

Areas of expertise include backend system architecture (multi-region, serverless, microservices), cloud-native development (AWS ECS, AWS Lambda, GCP, Docker, Kubernetes), polyglot backend development (Rust, Node.js, Golang), CI/CD and DevOps pipelines, monorepo and engineering governance, technical team leadership, as well as API/system integration and machine learning service integration.
